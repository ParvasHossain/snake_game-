# Snake Game - Laravel Edition

A classic Snake game built using PHP and the Laravel framework.

## Features

* Classic arcade Snake gameplay.
* Built with Laravel backend architecture.
* Responsive design and interactive controls.

## Requirements

* PHP >= 8.1
* Composer
* Node.js & NPM
* MySQL / MariaDB (or SQLite)
